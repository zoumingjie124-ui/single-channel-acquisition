## 2. 代码核算（只读，未修改）

### 2.1 换算公式

```c
uint16_t app_measure_raw_to_mv(uint16_t raw)
{
  return (uint16_t)(((uint32_t)raw * APP_ADC_VREF_MV) / APP_ADC_FULL_SCALE);
}
```

| 项 | 核算 |
|---|---|
| 中间量 | `4095 × 3300 = 13,513,500` < 2³²（4.29e9），**不会溢出** |
| 顺序 | 先乘后除，整数运算，无浮点 |
| 取整 | 向下截断，误差 ∈ (−0.806, 0] mV，**系统性偏低不超过 1 LSB** |
| 边界 | `raw=4095` → 3300 mV；`raw=0` → 0 mV，两端都正确 |

### 2.2 为什么这是"比例测量"

STM32F103C8T6 是 LQFP48 封装，**VREF+ 与 VDDA 在片内连在一起**，没有独立参考引脚。
所以：

```
满量程读数 = raw × 3300 / 4095，其中 3300 是"认为的"参考值
实际读数 = raw × VDDA / 4095
```

若板上 VDDA 实际是 3.28 V，满量程仍然显示 3300 mV（因为分子分母用了同一个假设值），
**误差被抵消**——这叫比例测量。它的好处是"相对测量准"，坏处是：

> **读数不能证明板上 3.3 V 真的是 3.300 V。**

这也解释了阶段一 §9 里那个结论：满量程 3299.87 mV 只证明"满码与换算正常"，
不证明绝对电压。

### 2.3 量化与分辨率

| 项 | 值 | 说明 |
|---|---|---|
| 1 LSB | 3300 / 4095 = **0.806 mV** | ADC 本身的分辨率 |
| 上报格式 | 整数 mV | 每 mV 约 1.24 个码 |
| 有效分辨率 | **1 mV** | 一旦转成整数 mV，亚毫伏信息就没了 |
| 滤波能否提高分辨率 | **不能** | 输入已量化，平均只能降噪声，不能恢复被截掉的位 |

这是设计选择（协议用 uint16 毫伏，够用且省带宽），不是缺陷。

### 2.4 其他配置

| 项 | 值 | 影响 |
|---|---|---|
| 采样时间 | `ADC_SAMPLETIME_55CYCLES_5` | 源阻抗容限宽，10k 电位器分压中点（约 2.5 kΩ）足够 |
| 触发 | TIM3 TRGO，100 Hz | 每 10 ms 一次单次转换 |
| 对齐 | 右对齐，12 位 | — |
| 限幅滤波 | `APP_RATE_LIMIT_MV = 0` | **当前关闭**；README 写"可选限幅"，一致 |

## 3. 静置测量（噪声与滤波器效果）

输入固定在电位器中点，采 4 s（400 帧）：

```
样本数 400  时长 4.00 s
raw_mv    均值 1530.33   min 1527   max 1538   峰峰 11 mV   标准差 2.40 mV
filt_mv   均值 1529.90   min 1528   max 1532   峰峰  4 mV   标准差 1.00 mV
```

| 指标 | 数值 | 解读 |
|---|---|---|
| 噪声（raw） | σ = 2.40 mV ≈ 3.0 LSB，峰峰 11 mV ≈ 14 LSB | 面包板 + 杜邦线的正常水平 |
| 噪声（filt） | σ = 1.00 mV，峰峰 4 mV | 明显的平滑效果 |
| 抑制比 | **2.40×** | 8 点平均理论 √8 = 2.83×，实测略低是被 1 mV 量化地板卡住 |
| 均值偏移 | raw 1530.33 → filt 1529.90（−0.43 mV） | 平均后再截断造成的偏差，≤1 mV |

> 这条同时验证了 `app_filter.c` 的滑动窗口实现是正确的（若是窗口错位或忘记减旧值，
> 均值会明显偏移，实测只差 0.43 mV）。

## 4. 扫掠测量（826–3300 mV）

25 秒采集，前 12.8 秒手拧电位器从 826 mV 到 3300 mV，之后停在顶端：

```
电平范围 826 ~ 3300 mV（跨度 2474 mV，2503 点）
移动段：样本 1 ~ 1276（1276 点，约 12.8 s）
移动段趋势 上升；明显反向跳变 46 次 / 1275 个相邻对（3.61%）
相邻步长：中位 1 mV/点，最大 36 mV/点
疑似跳变（>20 mV） 9 处
去趋势残差（窗口 ±6 点）：标准差 1.25 mV（MAD 估计）
残差峰峰 40.2 mV；范围 −20.3 ~ +19.9
电平覆盖：12 / 16 段非空
```

### 4.1 怎么读这些数

| 观察 | 判断 |
|---|---|
| 中位步长 1 mV/点 ≈ 100 mV/s | 手拧速度正常，采样没有明显漏点（若漏采，步长会成倍跳） |
| 9 处 >20 mV 的跳变 | **电位器接触噪声**（碳膜磨损/手抖），不是 ADC 问题——同一位置静置时不会出现 |
| 46 次反向跳变（3.6%） | 同上，手拧过程的小幅回抖；静置时不出现 |
| 残差 σ 1.25 mV 与静置 σ 2.40 mV 同量级 | 扫掠本身没引入额外干扰 |
| 残差峰峰 40 mV | 由上述接触噪声造成，属离群点，故用 MAD 估计而非标准差 |

### 4.2 那 4 个"空段"是什么

空段是 **0–825 mV** 这四段。原因是**电位器没拧到最低端**（扫掠起点就是 826 mV），
不是采样缺口——同一时刻 `seq8` 连续、`drop` 为 0。

要补齐这一段，需要从 0 V 起扫；见 §8 待办。

## 5. 滤波器群延迟（实测）

手拧扫掠是一段斜坡，`filt` 相对 `raw` 的滞后可以直接用互相关求出，**不需要人工做阶跃**。

取移动段前 1180 点（11.8 s），对不同滞后 L 计算均方误差：

| 滞后 L | 0 | 1 | 2 | **3** | **4** | 5 | 6 | 7 | 8 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 延迟 (ms) | 0 | 10 | 20 | **30** | **40** | 50 | 60 | 70 | 80 |
| MSE (mV²) | 141.6 | 79.1 | 36.1 | **13.6** | **11.8** | 30.8 | 70.3 | 129.6 | 209.4 |

- **最小值在 L = 4（40 ms）**，L = 3（30 ms）几乎相同（13.6 vs 11.8）
- 理论值：8 点移动平均 `filt[n] = mean(raw[n-7..n])`，对斜坡等效滞后
  `(N-1)/2 = 3.5 点 = 35 ms`
- 实测落在 3 与 4 之间 → **与理论一致**（整数滞后无法表达 3.5）

**这条的实际意义**：从电压变化到上位机曲线反映出来，固定约 **35–40 ms**。
如果做闭环控制，这个延迟必须算进相位裕度；本项目只做监测，可接受。

## 6. 误差分析：能说明什么、不能说明什么

### 6.1 能说明

| 结论 | 支撑数据 |
|---|---|
| 换算公式正确、无溢出 | §2.1 核算 + 零/满量程两端读数（1.75 mV / 3299.87 mV） |
| 滤波器实现正确（无窗口错位） | 静置均值偏移仅 −0.43 mV |
| 滤波器延迟符合理论 | 实测 35–40 ms vs 理论 35 ms |
| 中间量程（826–3300 mV）单调、无异常台阶 | 扫掠 2474 mV，无整段丢失，步长中位 1 mV |
| 噪声水平可用于 2400/3000 mV 判级 | σ 2.40 mV 占 WARN 阈值 0.1% |

### 6.2 不能说明

| 不能说明 | 原因 |
|---|---|
| **绝对电压精度**（如"读 1650 mV 时真实是 1648 mV"） | 无外部表计；且 VREF+ 与 VDDA 同源，自测必然自洽 |
| **INL / DNL** | 固件只上报换算后的 mV，不上报 ADC 原始码，无法统计每个码的命中次数 |
| 0–825 mV 段的线性 | 本次扫掠没覆盖（电位器未拧到底） |
| 长期漂移 | 只有单次测量 |

### 6.3 三点标定为什么必须外部参考

任务书建议测 25% / 50% / 75%（825 / 1650 / 2475 mV）。若用"理论值"当参考：

```
理论 1650 mV → 固件按 raw=2048 换算 → 1650 mV → 误差 0.00 mV
```

这不是测出来的，是**同一个公式算两遍**——循环论证。
只有万用表读到的实际电压才是独立参考。

## 7. 是否需要改代码：结论是**不需要**

| 候选改动 | 判断 | 理由 |
|---|---|---|
| 把 `/4095` 改成 `/4096` | **不改** | 12 位 ADC 满码是 4095，用 4095 才能保证满量程对应 3300；用 4096 会让满量程偏低 0.8 mV，属"看起来更数学正确"的错误 |
| 改成四舍五入减少截断偏差 | **不改** | 偏差 ≤0.8 mV，占 WARN 阈值 0.03%，且会改变所有历史数据的口径 |
| 增加 VDDA 实测 + 校准系数 | **暂不加** | 需要额外硬件（内部参考通道或外部基准）。当前用途是判级（2400/3000 mV），比例测量足够；若将来要"报绝对电压"，才需要 |
| 上报 ADC 原始码（为了 DNL/INL） | **不加** | 属协议变更；且 DNL/INL 对"判级"没有实际价值，属芯片出厂指标 |
| 提高上报分辨率（0.1 mV） | **不加** | 噪声 σ=2.4 mV 远大于 0.1 mV，提高位数只增加带宽不增加信息 |

一句话：**当前实现与该项目的用途匹配，没有发现需要改的缺陷。**

## 9. 复现命令

```bat
:: 静置（无外部参考时只看噪声）
python host\tools\lin.py COM6 hold --sec 4

:: 静置 + 外部参考（有万用表时）
python host\tools\lin.py COM6 hold --sec 4 --ref 1653

:: 扫掠 25 s（期间匀速拧电位器），落 CSV
python host\tools\lin.py COM6 sweep --sec 25 --csv docs\LIN_SWEEP.csv

:: 离线复算（不接板子）
python host\tools\lin.py COM6 sweep --from-csv docs\LIN_SWEEP.csv

:: 阶跃响应（可选，需快速拧过 300 mV 以上）
python host\tools\lin.py COM6 step --sec 15
```
