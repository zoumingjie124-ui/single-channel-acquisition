三、计算（百分比一律以 FS = 3300 mV 为分母）
----------------------------------------------------------------
V0 = 0.000 V      M0 = 1.58 mV
V1 = 3.245 V      M1 = 3299.75 mV

零点偏移 = M0 - V0 = +1.58 mV                        门槛 <=5 mV   -> PASS
           含表不确定度上界 1.58 + 3 = 4.58 mV（保守值 (b)），仍 <=5 mV -> PASS（余量 0.42 mV）
           （按 (a) 为 1.58 + 2 = 3.58 mV）

满量程误差 = M1 - V1 = 3299.75 - 3245 = +54.75 mV
            = 54.75 / 3300 = **1.66 % FS**            门槛 <=1 % FS -> FAIL（点估计）
            （若以表读数为分母：54.75 / 3245 = +1.69 %，这是"相对读数的偏差"，
              不是 %FS，两者不可混用）

跨度误差 = (M1 - M0) - (V1 - V0) = 3298.17 - 3245 = +53.17 mV
            = 53.17 / 3300 = **1.61 % FS**            门槛 <=0.5 %FS -> FAIL（点估计）

表不确定度（两个来源并列，本轮取较大者作保守界；原件未核对）：
    (a) 用户转述 ±(0.8 % 读数 + 2 字)
        3.245 V 处 = 0.8% x 3245 = 25.96 mV，+2 字 = 2 mV => ±27.96 ≈ ±28.0 mV
        折成 %FS = 27.96 / 3300 = 0.85 % FS
    (b) 转载说明书页 ±(1.2 % + 3)   <- 本轮采用
        3.245 V 处 = 1.2% x 3245 = 38.94 mV，+3 字 = 3 mV => ±41.94 ≈ ±41.9 mV
        折成 %FS = 41.94 / 3300 = **1.27 % FS**
    原件未核对 => 取较大者 (b) 作保守界；下列区间一律按 (b) 计

    满量程误差真实区间 = 54.75 ± 41.9 mV = **+12.8 ~ +96.7 mV**
    折成 %FS           = **+0.39 % ~ +2.93 % FS**
    跨度误差真实区间   = 53.17 ± 41.9 mV = **+11.3 ~ +95.1 mV**
    折成 %FS           = **+0.34 % ~ +2.88 % FS**
    => 点估计 1.66 %FS 超 1 % 门槛，门槛 33 mV 仍落在区间内，区间跨门槛：
       不能写"确定超过 1 %FS"，也不能写"已验证 <=1 %FS"

    【若日后给出原件公式】按原件重算一次即可；结论的三句口径不变，只换数字。

【归因：只到"一致"这一档，不到"验证"】
    PA1 接 3.3 轨时，输入就是 VDDA 本身，ADC 基本满码（均值 4094.7 LSB、最小 4090、最大 4095），
    固件按 4095 x 3300 / 4095 = 3300 mV 折算，所以

        54.75 mV = 3300 - 3245

    是一个**算术恒等式**，不是对 ADC 增益的独立验证。它能说明的只有：
    "设备读数比外部表读数高 54.75 mV"，且这个差**与'固件假设 3.300 V、轨压更低'一致**。
    **在表的不确定度（保守值 (b) ±41.9 mV）内，无法区分"板偏（VDDA 真的低 55 mV）"与
    "表偏（表读数偏低 55 mV）"**——两者都能解释这 54.75 mV。

    因此本轮**不能**得出"ADC 自身增益误差 < 0.3 LSB"这类结论（早期版本这样写过，已撤回）：
    0.25 mV 的差值只是"表读数与固件常数 3300 之差"，与 ADC 无关。
    要真正分离板偏与表偏，需要一次比例测量（见第五节第 4 项）。

【4094.7 LSB 能否当"同网络"证据 —— 查数据后的结论】
    逐样本原始码**未存档**（calib.py 只打印 min/mean/max，不落 CSV），
    因此**标准差、以及"取 4095 的比例"无法给出**；可用的只有既有的三条统计：
        raw_mv  min/mean/max = 3296 / 3299.75 / 3300 mV
        折算成码             = 4090 / 4094.7  / 4095 LSB   （峰峰 5 LSB）
    可见**并不是"全部 4095"**：有样本低到 4090，说明输入没有被完全压在满码上，
    即 PA1 节点与 VDDA 的差在 **<=5 LSB（约 4 mV）** 量级（其中还含 ADC 自身噪声）。
   注意：该界来自"样本最小值"，是**上界、不是测出来的差值**。
    => 这**约束了该测点的电压差**（代理口径的偏差 <=4 mV，相对 54.75 mV 与 +/-41.9 mV 可忽略），
       **但不构成"同网络"的证明**。


四、对告警阈值的影响（此前未记录）
----------------------------------------------------------------
设备读数 mv_rep = V_in x 3300 / 3245 = V_in x 1.016949
故标称阈值在真实电压上偏低 1.69%：
    WARN 2400 mV  ->  实际 2360.0 mV 触发
    CRIT 3000 mV  ->  实际 2950.0 mV 触发
对"是否报警"的判定无影响（读数与阈值同口径）；
但任何"绝对电压"表述都要带这个偏差。
