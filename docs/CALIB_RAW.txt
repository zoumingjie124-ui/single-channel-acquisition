三、计算
----------------------------------------------------------------
V0 = 0.000 V      M0 = 1.58 mV
V1 = 3.245 V      M1 = 3299.75 mV

零点偏移 = M0 - V0 = +1.58 mV                    门槛 ≤5 mV      -> PASS
                  含表不确定度上界 1.58+2 = 3.58 mV，仍 ≤5 mV  -> PASS

满量程误差 = M1 - V1 = 3299.75 - 3245 = +54.75 mV
            相对 V1  = 54.75 / 3245 = +1.688 %
            门槛 ≤33 mV（1% FS）                              -> FAIL（点估计）

跨度误差 = (M1 - M0) - (V1 - V0) = 3298.17 - 3245 = +53.17 mV
            相对 V1  = +1.638 %
            门槛 ≤16.5 mV（0.5% FS）                           -> FAIL（点估计）

理论预测（假设误差全部来自参考电压）：
    固件满码折算 3300 mV，VDDA 实际 3245 mV
    预期偏差 = 3300 - 3245 = 55.00 mV （+1.695%）
    实测     = 54.75 mV （+1.688%）
    差       = 0.25 mV ≈ 0.31 LSB
    => ADC 自身增益误差 < 0.3 LSB（不可测），偏差全部来自参考电压假设

表不确定度（±(0.8% 读数 + 2 字)）：
    3.245 V 处 = 0.8% x 3245 = 25.96 mV，+2 字 = 2 mV  => ±27.96 ≈ ±28.0 mV
    故满量程误差真实区间 ≈ +26.8 ~ +82.7 mV  ( +0.83% ~ +2.55% FS )
    => 点估计超 1% 门槛，但区间跨门槛：
       不能写"确定超过 1% FS"，也不能写"已验证 ≤1% FS"

四、对告警阈值的影响（此前未记录）
----------------------------------------------------------------
设备读数 mv_rep = V_in x 3300 / 3245 = V_in x 1.016949
故标称阈值在真实电压上偏低 1.69%：
    WARN 2400 mV  ->  实际 2360.0 mV 触发
    CRIT 3000 mV  ->  实际 2950.0 mV 触发
对"是否报警"的判定无影响（读数与阈值同口径）；
但任何"绝对电压"表述都要带这个偏差。
