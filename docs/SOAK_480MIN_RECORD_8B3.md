## 4. 打点（479 条）与 ΔSAMPLE 分布

- 478 个区间：**ΔSAMPLE = 6000 ×88 / 6001 ×374 / 6002 ×16**，**max 偏差 2**；

  因此**不需要**用 NTP 台阶解释（也已由事件日志独立排除，见 §7）。

## 6. H11 的算法与跨轮对照

```
T0  uptime0 = 200795 ms   @ 2026-11-05 23:10:46.618
T1  uptime  = 29034427 ms @ 2026-11-06 07:11:16.173
Δuptime = 28833632 ms    Δwall = 28829555 ms    差 = +4077 ms
偏差 = 4077 / 28829555 = 0.01414 %   → 141 ppm（设备时基偏快）
```

- 终点 `uptime` 取自 1 Hz STAT，存在约 **±1 s 量化**（≈±0.0035 %），故**不宣称毫秒级精确**。
- **与 8B-2 的对比（重要）**：8B-2（`en=0`）报的是 **0.0039 %**，本轮是 **0.0141 %**。
  8B-2 那次窗口内有一次主机 NTP **+2950 ms** 前跳，把 `Δwall` 拉长、抵消了约 2.95 s；
  本轮 `NoSync`、事件日志无时钟阶跃，**测到的是未经抵消的真实值 ≈141 ppm**，与 8B-2 分段拟合出的 140 ppm 吻合。
  → 结论：两轮不是"设备变差了"，**8B-2 的 0.0039 % 是表观值**，141 ppm 才是该构建的真实量级。
- 因此 **H11 不得跨轮次比较**，只能逐轮对照"是否 < 0.1 %"。

## 8. 终点读数与 `conf` 的口径

```
07:11:16.173  STAT t=29034427ms n=2884363 drop=0 adc=0 uart=0 rxf=0 frm=0 chg=0 cmd=0/0 txd=0B
              ERRSRC ore=0 fe=0 ne=0 pe=0 pto=0 rxrst=0/0
              DIAG en=1 state=2 conf=0 span=10 blk=88 unev=0 mask=1 rep=1
07:11:20.640  STAT t=29040095ms n=2884930 … DIAG en=1 state=2 conf=0 span=11 blk=49 …
```

- 设备侧错误计数**全程为 0**（差值 0、绝对 0 两者一致）。
- `n` 对账：`n_end − n_T0 = 2,884,363 − 1,000 = 2,883,363`；
  日志 SAMPLE 2,880,407 + 窗口差 29.555 s × 100 Hz (=2,956) = **2,883,363** → **闭合，残差 <1 样本**。
- **`conf = 0` 是预期内的**：`reset`（23:10:36）把 `conf` 清零，而当时模块**已经处于 ACTIVE**，
  之后 8 小时输入一直卡死、没有发生 CLEAR→CONFIRM 的新确认，所以 `conf` 保持 0（**增量 0**）。
  与 X2 的 `conf 1→1`（增量 0）**结论相同、起点不同**，引用时不得混用绝对值。
- `mask=1 / rep=1 / state=2 / unev=0`：故障仍上报且无未决事件，符合"诊断开启态长期运行不应产生新事件"。
- **`blk` 的含义（已查源码）**：`blk` = `app_diag_block_samples()`，即**当前未结算的 1 s 统计块内已计入的样本数**
  （100 Hz ⇒ 0–100），块结算后清零（`App/Src/app_task.c:343`、`App/Inc/app_diag.h:44`、`App/Src/app_diag.c:88`）。
  T0=73 → 终点=88 → 二次读取=49 的**非单调是设计使然**，与健康状况无关，**不作判据**。
- **一处更正**：起跑时按"`conf` 会 0→1"预期记录，该预期**错误**——`confirm_cnt` 只在
  `CLEAR/CONFIRMING → ACTIVE` 时自增（`App/Src/app_diag.c:120`），ACTIVE 期间不重复确认
  （同文件 L129–134）。`reset` 清零时模块已 ACTIVE，故全程 0。详见 `STAGE8B_REPORT` §9.5。

## 11. 能证明 / 不能证明

**能**：该构建在诊断开启态连续 8 小时无复位（BOOT 0）、无链路中断、无采样环溢出、
无帧错误/ADC 错误/UART 错误、无可分辨序号缺口；采样率与时基均在设计容差内。

**不能**：不能证明绝对电压精度（R2 与本轮无关；该测项已于 2026-11-07 单独实测、记 **部分关闭**——
零点 PASS、满量程 1.66 %FS 点估计超门槛而区间跨门槛，见 `CALIB_ABSOLUTE.md` §6、`TEST_REPORT.md` §21）；
不能证明真实传感器失效场景（R19 只有电位器）；
不能把"未检出缺口"说成"绝对零丢失"（8 位序号盲区）；不能外推到 `en=0` 之外的其它配置
（`en=0` 已有 8B-2 的独立结论）。
